# 会话

Pi 会将对话保存为会话，便于你继续工作、从较早的轮次创建分支，以及重访之前的路径。

## 会话存储

会话会自动保存到 `~/.pi/agent/sessions/`，并按工作目录组织。每个会话都是一个采用树结构的 JSONL 文件。

```bash
pi -c                  # 继续最近的会话
pi -r                  # 浏览并选择过去的会话
pi --no-session        # 临时模式；不保存
pi --name "my task"    # 启动时设置会话显示名称
pi --session <path|id> # 使用指定的会话文件或部分会话 ID
pi --fork <path|id>    # 将会话文件或部分会话 ID 分叉为新会话
```

在交互模式中使用 `/session`，可以查看当前会话文件、会话 ID、消息数、token 数和费用。

有关 JSONL 文件格式和 SessionManager API，请参阅[会话格式](session-format.zh-CN.md)。

## 会话命令

| 命令 | 说明 |
|---------|-------------|
| `/resume` | 浏览并选择以前的会话 |
| `/new` | 启动新会话 |
| `/name <name>` | 设置当前会话的显示名称 |
| `/session` | 显示会话信息 |
| `/tree` | 在当前会话树中导航 |
| `/fork` | 从之前的用户消息创建新会话 |
| `/clone` | 将当前活动分支复制到新会话 |
| `/compact [prompt]` | 总结较早的上下文；参阅[上下文压缩](compaction.zh-CN.md) |
| `/export [file]` | 将会话导出为 HTML |
| `/share` | 作为私有 GitHub gist 上传，并生成可分享的 HTML 链接 |

## 恢复和删除会话

`/resume` 会打开当前项目的交互式会话选择器。`pi -r` 会在启动时打开相同的选择器。

在选择器中，你可以：

- 直接输入进行搜索
- 使用 Ctrl+P 切换路径显示
- 使用 Ctrl+S 切换排序模式
- 使用 Ctrl+N 筛选有名称的会话
- 使用 Ctrl+R 重命名
- 使用 Ctrl+D 删除，然后确认

如果 `trash` CLI 可用，Pi 会使用它删除文件，而不是永久移除文件。

## 命名会话

使用 `/name <name>` 设置易于阅读的会话名称：

```text
/name 重构身份验证模块
```

使用 `--name` 或 `-n` 在启动时设置名称：

```bash
pi --name "Refactor auth module"
pi --name "CI audit" -p "Review this build failure"
```

命名后的会话更容易在 `/resume` 和 `pi -r` 中找到。

## 使用 `/tree` 创建分支

会话以树结构存储。每个条目都有 `id` 和 `parentId`，当前位置是活动叶节点。使用 `/tree` 可以跳转到之前的任意位置并从那里继续，而无需创建新文件。

<p align="center"><img src="images/tree-view.png" alt="树视图" width="600"></p>

结构示例：

```text
├─ user: "你好，可以帮帮我吗……"
│  └─ assistant: "当然！我可以……"
│     ├─ user: "试试方案 A……"
│     │  └─ assistant: "对于方案 A……"
│     │     └─ user: "成功了……"  ← 活动节点
│     └─ user: "其实还是方案 B……"
│        └─ assistant: "对于方案 B……"
```

### 树操作

| 按键 | 操作 |
|-----|--------|
| ↑/↓ | 在可见条目间导航 |
| ←/→ | 向上/向下翻页 |
| Ctrl+←/Ctrl+→ 或 Alt+←/Alt+→ | 折叠/展开，或在分支片段之间跳转 |
| Shift+L | 设置或清除所选条目的标签 |
| Shift+T | 切换标签时间戳 |
| Enter | 选择条目 |
| Escape/Ctrl+C | 取消 |
| Ctrl+O | 循环切换筛选模式 |

筛选模式包括：默认、不显示工具、仅用户、仅有标签和全部。通过[设置](settings.zh-CN.md)中的 `treeFilterMode` 配置默认值。

### 选择行为

选择用户消息或自定义消息时：

1. 将叶节点移动到所选消息的父节点。
2. 将所选消息的文本放入编辑器。
3. 你可以编辑并重新提交，从而创建新分支。

选择 assistant、工具、压缩或其他非用户条目时：

1. 将叶节点移动到该条目。
2. 保持编辑器为空。
3. 你可以从该位置继续。

选择根用户消息会将叶节点重置为空对话，并把原始提示放入编辑器。

## `/tree`、`/fork` 和 `/clone`

| 功能 | `/tree` | `/fork` | `/clone` |
|---------|---------|---------|----------|
| 输出 | 同一个会话文件 | 新会话文件 | 新会话文件 |
| 视图 | 完整树 | 用户消息选择器 | 当前活动分支 |
| 典型用途 | 在原处探索替代方案 | 从较早的提示启动新会话 | 继续之前复制当前工作 |
| 摘要 | 可选的分支摘要 | 无 | 无 |

希望将替代方案集中保存在一起时使用 `/tree`。需要单独的会话文件时使用 `/fork` 或 `/clone`。

## 分支摘要

当 `/tree` 从一个分支切换到另一个分支时，Pi 可以总结被放弃的分支，并将摘要附加到新位置。这样无需重放整个分支，也能保留离开路径中的重要上下文。

出现提示时，可选择以下选项之一：

1. 不生成摘要
2. 使用默认提示生成摘要
3. 使用自定义重点说明生成摘要

有关分支摘要的内部原理和扩展 hook，请参阅[上下文压缩](compaction.zh-CN.md)。

## 会话格式

会话文件采用 JSONL 格式，其中包含消息条目、模型变更、思考级别变更、标签、上下文压缩、分支摘要和扩展条目。

有关解析器、扩展、SDK 用法和完整的 SessionManager API，请参阅[会话格式](session-format.zh-CN.md)。
